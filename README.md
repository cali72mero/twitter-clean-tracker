## 🚀 Was macht dieses Tool?

Dieses Projekt stellt ein **Bookmarklet** (Lesezeichen-Skript) bereit, das Twitter manipuliert, um deine Privatsphäre zu schützen und Werbung zu blockieren.

### Features
1.  **✅ Kein Login nötig:** Du kannst öffentliche Profile und Tweets lesen, ohne dich anzumelden.
2.  **🛡️ Anti-Tracking:** Löscht Cookies, LocalStorage und SessionStorage sofort.
3.  **🎭 Fake Identität:** Ändert deinen "User-Agent", damit Twitter denkt, du bist ein generischer Chrome-Browser auf Windows 10 (schützt vor Fingerprinting).
4.  **🧹 Clean UI:** Entfernt Werbung ("Promoted Tweets"), "Wem folgen?"-Vorschläge und nervige Skeletons.
5.  **⚡ Performance:** Die Seite lädt schneller, da Tracking-Skripte und unnötige Elemente entfernt werden.

---

## 📦 Installation

1.  Öffne die [Projekt-Webseite](https://cali72mero.github.io/twitter-clean-tracker/).
2.  Ziehe den **"💾 Als Bookmarklet Installieren"** Button in deine Lesezeichen-Leiste.
3.  Fertig!

## 🎮 Benutzung

1.  Gehe auf [Twitter.com](https://twitter.com) (oder x.com).
2.  Klicke auf dein neues Lesezeichen **"🐦 CleanTwitter"**.
3.  Das Skript startet, reinigt die Seite und zeigt eine Meldung "🐦 Twitter Clean Mode active!".

---

## ⚠️ Disclaimer

Dieses Tool dient ausschließlich **Bildungs- und Privatsphäre-Zwecken**. Es manipuliert nur die lokale Darstellung der Webseite in deinem Browser. Es umgeht keine serverseitigen Sperren, sondern entfernt nur Client-seitige Overlay-Elemente und Tracking-Daten.
