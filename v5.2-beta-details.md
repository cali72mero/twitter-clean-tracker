# 🐦 CleanTwitter v5.2 BETA — Detaillierte Dokumentation

> Vollständige Erklärung von v5.2: Was neu ist, was funktioniert, was nicht, und was gegenüber v4.2.2 besser wurde.

---

## 🔍 Was ist v5.2 BETA?

v5.2 ist die Weiterentwicklung des stabilen v4.2.2. Es baut auf denselben Grundlagen auf, fügt aber deutlich mehr Features hinzu: einen eingebauten Auto-Scroller, Stealth-Modus gegen Ban-Risiko, und vor allem einen **echten Cache-Clear**, der das lästigste Problem mit früheren Versionen gelöst hat.

**BETA = mehr Features, aber noch nicht so langzeit-getestet wie v4.2.2 STABLE.**

---

## ✅ Was kann v5.2?

### 1. 👀 Tweets automatisch speichern
Sobald du das Bookmarklet auf Twitter aktivierst, scannt es beim Scrollen alle sichtbaren Tweets und speichert sie lokal:
- Tweet-Text
- Benutzername
- Datum
- Bilder (auch bei 4 Bildern pro Post!)
- Videos (MP4)

**Beispiel:**
```
Du scrollst durch deinen Twitter-Feed.
Das Bookmarklet läuft im Hintergrund.
Badge zeigt: ♾️ 247
→ 247 Tweets wurden automatisch gespeichert!
```

---

### 2. 🔽 Auto-Scroller (NEU in v5.1)
Klicke den **🔽 Scroll**-Button im Panel. Das Bookmarklet scrollt jetzt automatisch langsam durch deinen Feed.

| Einstellung | Standard | Bereich |
|---|---|---|
| Scroll-Geschwindigkeit | 30 px/s | 10–200 |
| Pause nach Aktivität | 2000ms | 500–10000 |

**Beispiel:**
```
Du öffnest Twitter, drückst 🔽 Scroll, lehnst dich zurück.
Das Tool scrollt automatisch runter und speichert alles.
Bei manueller Maus-Bewegung pausiert Scroll automatisch.
```

---

### 3. 🛡️ Stealth Mode (NEU in v5.1)
Statt jeden Tweet exakt jede 1,5 Sekunden zu scannen (erkennbares Bot-Muster), nutzt v5.2 **zufällige Pausen** zwischen 2 und 6 Sekunden.

```
Ohne Stealth: Scan → 1.5s → Scan → 1.5s → Scan (auffällig)
Mit Stealth:  Scan → 2.3s → Scan → 5.1s → Scan (unauffällig)
```

---

### 4. ⏸️ Rate Limit Protection (NEU in v5.1)
Nach 50 gescannten Tweets hält das Bookmarklet automatisch 30 Sekunden an. Das Badge zeigt `⏸️ Limit`.

```
Badge-Anzeigen:
♾️ 247    = Normal, läuft
⏸️ Limit  = Pause (30s), dann weiter
⏳ Sync...  = Sendet Daten an Dashboard
```

---

### 5. 🗑️ Echter Cache-Clear (HAUPTFIX in v5.2)
Das ist der wichtigste Fix. Klicke **🗑️ Clear** direkt auf Twitter → alle lokal gespeicherten Tweets werden gelöscht. Badge zeigt sofort **0**.

Danach im Dashboard: **"Cache leeren"** drücken → Dashboard-Anzeige wird ebenfalls 0.

---

### 6. 👀 View-Button (Dashboard öffnen)
Klicke **👀 View** im Panel. Das Dashboard öffnet sich in einem neuen Tab und alle gespeicherten Tweets werden importiert.

---

### 7. 🗂️ ZIP-Export & HTML-Archiv
Im Dashboard kannst du alles exportieren:
- **ZIP:** Alle Bilder & Videos als .zip heruntergeladen
- **HTML:** Schickes Archiv mit Bilder-Grid, lokal lesbar

---

### 8. ⚙️ Einstellungen im Dashboard
Alle Features ein-/ausschaltbar:
- Stealth Mode
- Rate Limit Protection
- Auto-Scroller Geschwindigkeit & Pause
- Retweet-Filter
- Thread-Erkennung
- Download-Buttons auf Twitter
- Grünes/Rotes Badge

| 🌍 Andere Tabs analysieren | Nur aktiver Twitter-Tab |

## 🐛 Gelöste Bugs in v5.2

### Bug #1: Zombie-Daten nach Cache-Clear 💀
**Problem:** Wenn du "Cache leeren" im Dashboard klicktest, wurden die Daten sofort wieder importiert (Badge sprang von 0 auf 1744).

**Ursache:** Dashboard (github.io) und Bookmarklet (x.com) haben **getrennten Browser-Speicher** (Cross-Origin). Dashboard-Cache leeren = nur github.io Storage gelöscht. Twitter (x.com) hatte noch alles und schickte es beim nächsten "View"-Klick wieder.

**Fix:** Neuer **🗑️ Clear**-Button direkt im Bookmarklet-Panel löscht den x.com-Speicher direkt.

```
Vorher (buggy):
[Clear im Dashboard] → github.io Storage leer → Badge 0
[View klicken] → x.com sendet 1744 Tweets → Badge 1744 ❔

Jetzt (v5.2 fixed):
[🗑️ Clear auf Twitter] → x.com Storage leer → Badge 0 ✅
[Clear im Dashboard] → github.io Storage leer → Anzeige 0 ✅
```

### Bug #2: clearCache() Reload-Problem (v5.1)
**Problem:** `clearCache()` machte `window.location.reload()`. Das war nervig und unnötig.

**Fix:** v5.2 nutzt wie v4.2.2 einfach `localStorage.removeItem()` + `loadCache()`. Kein Reload mehr.

## 📍 Schritt-für-Schritt: Cache leeren (v5.2)

```
1. Auf Twitter (Bookmarklet läuft):
   → Klicke 🗑️ Clear im Panel
   → Bestätige mit OK
   → Badge zeigt ♾️ 0

2. Im Dashboard (GitHub Pages):
   → Klicke "Cache leeren"
   → Bestätige mit OK  
   → Anzeige zeigt 0 Tweets

Fertig! Beide Speicher sind geleert.
```
